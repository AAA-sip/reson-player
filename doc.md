# 🎵 Документация Smart Music Player

## 📱 Обзор приложения

**Smart Music Player** - это умный локальный музыкальный плеер для Android с AI-помощником, который делает прослушивание музыки более интеллектуальным и персонализированным.

### Основная идея
Пользователь слушает свою локальную музыку, а приложение помогает ему находить нужные треки, улучшает метаданные, создает умные плейлисты и дает персональные рекомендации.

### Ключевые особенности
- 🎧 Воспроизведение локальной музыки
- 🤖 AI-помощник для умного поиска и рекомендаций
- 🎨 Кастомные темы оформления
- 📝 Синхронизированные тексты песен
- 🔄 Умная очередь воспроизведения
- 🌐 Обогащение метаданных из интернета

## 🏠 1. Главный экран (Home)

### Что видит пользователь

**При открытии приложения:**
- Вверху экрана большое приветствие: *"Сегодня погода отличная, Али!"*
- Через 3 секунды меняется на: *"Discover"*
- Две кнопки в углу: Настройки и Поиск
- Внизу экрана всегда видно мини-плеер (если играет музыка)

**При прокрутке вниз:**
- Приветствие уменьшается и остается в верхней панели
- Становится обычным заголовком

### Секции на главном экране

**1. Discover (Открывай новое)**
- Рекомендованные треки на основе того, что слушал
- "Попробуй послушать..." - новые треки из библиотеки
- Карточки с обложками и названиями

**2. История прослушиваний**
- Последние 10-20 прослушанных треков
- Можно быстро вернуться к недавно прослушанному

**3. Быстрый доступ**
- Избранные плейлисты
- Часто слушаемые альбомы
- Топ артисты

**4. Рекомендации дня**
- "Что послушать сегодня?"
- AI подбирает треки под время суток и настроение
- Например, утром - бодрая музыка, вечером - спокойная

### Логика работы

**Приветствие:**
- Меняется в зависимости от времени суток
- Может быть персонализированным: погода, настроение, события
- Примеры: "Доброе утро!", "Отличный вечер для музыки!", "С понедельником, Али!"

**Рекомендации:**
- Основаны на истории прослушиваний
- Учитывают время суток
- Анализируют что пользователь слушает часто
- Предлагают похожие треки

## 🔍 2. Поиск

### Обычный поиск

**Что можно искать:**
- Треки по названию
- Артистов
- Альбомы
- Плейлисты

**Как работает:**
- Начинаешь печатать - появляются подсказки
- Поиск идет по всей локальной библиотеке
- Результаты группируются: Треки / Артисты / Альбомы

### Умный поиск с AI

**Особенность:** можно искать не только по названию, но и по описанию

**Примеры запросов:**
- *"Грустная песня"* → находит треки с грустным настроением
- *"Энергичная музыка"* → треки с высоким BPM для тренировок
- *"Музыка для сна"* → спокойные, медленные композиции
- *"Похожие на Imagine Dragons"* → ищет похожих артистов

**Как это работает:**
- AI анализирует ваш запрос
- Понимает что вы ищете по настроению, темпу, жанру
- Фильтрует библиотеку по этим параметрам
- Если ничего не найдено локально, предлагает поискать в интернете

### AI-помощник в поиске

**Что он умеет:**
- Показывает топ чарты
- Рассказывает какие песни сейчас популярны
- Исправляет опечатки в названиях
- Дает советы: "Попробуй также послушать..."

**Пример диалога:**
```
Вы: "грусная песня"
AI: "Возможно вы ищете: 'грустная песня'? 
     Нашел 15 треков с грустным настроением в вашей библиотеке.
     Также можем найти в интернете популярные грустные песни."
```

## 🎵 3. Плеер

### Мини-плеер

**Где находится:** внизу экрана на любой странице

**Что показывает:**
- Обложка трека (маленькая)
- Название и артист
- Кнопка Play/Pause
- Полоска прогресса

**Действия:**
- Тап на плеер → открывается полноэкранный плеер
- Тап на Play/Pause → пауза/воспроизведение
- Свайп вниз → закрыть плеер

### Полноэкранный плеер

**Внешний вид:**
- Большая обложка альбома в центре
- Под обложкой: название трека, артист, альбом
- Полоса прогресса с временем
- Кнопки управления
- Дополнительные функции внизу

**Основные кнопки:**
- ⏮ Предыдущий трек
- ⏯ Play / Pause
- ⏭ Следующий трек
- 💚 Добавить в избранное

**Дополнительные кнопки:**
- 🔀 Перемешивание (обычное или умное)
- 🔁 Повтор (выкл / все / один трек)
- 📝 Показать текст песни
- ⏰ Таймер сна
- 📋 Очередь воспроизведения

### Умное перемешивание

**Обычное перемешивание:**
- Случайный порядок треков

**Умное перемешивание:**
- Группирует треки по жанру
- Учитывает темп (BPM) - плавный переход
- Не ставит подряд одного артиста
- Чередует быстрые и медленные композиции

**Перемешивание по настроению:**
- Только грустные
- Только веселые
- Только энергичные

### Очередь воспроизведения

**Что можно делать:**
- Смотреть что будет играть дальше
- Менять порядок (перетаскивать треки)
- Удалять треки из очереди
- Добавлять новые треки
- Сохранить очередь как плейлист

**Умная очередь:**
- AI может автоматически продолжить очередь похожими треками
- "Добавить похожие" → AI подберет треки в том же стиле

### Таймер сна

**Настройки:**
- Выбор времени: 15 мин, 30 мин, 1 час, до конца трека
- Плавное затухание звука
- Остановка после текущего трека

**Пример:** поставил таймер на 30 минут с затуханием → через 25 минут громкость начинает постепенно уменьшаться, через 30 минут музыка останавливается

### Тексты песен (Lyrics)

**Обычный режим:**
- Показывает все тексты песни
- Можно прокручивать

**Синхронизированный режим:**
- Текст подсвечивается в такт музыке
- Автоматическая прокрутка к текущей строке
- Тап на строку → перематывает к этому моменту

## 📚 4. Библиотека

### Разделы библиотеки

**1. Все треки**
- Список всех песен в телефоне
- Сортировка: по названию, артисту, дате добавления, длительности
- Фильтры: по жанру, году, избранному

**2. Артисты**
- Сетка с фото артистов
- Показывает количество треков и альбомов
- Тап на артиста → страница артиста

**3. Альбомы**
- Сетка с обложками альбомов
- Год выпуска и количество треков
- Тап на альбом → список треков альбома

**4. Плейлисты**
- Созданные пользователем
- Автоматические (AI-generated)
- Избранное (автоматический плейлист)

### Страница артиста

**Что показывает:**
- Большое фото артиста
- Имя и жанры
- Краткая биография
- Количество треков и альбомов
- Все альбомы артиста
- Популярные треки
- Похожие артисты

**AI-помощник здесь:**
- "Имя артиста неправильное" → предлагает исправить
- "Нет фото" → предлагает найти в интернете
- "Нет биографии" → предлагает загрузить с Last.fm

### Страница альбома

**Что показывает:**
- Обложка альбома
- Название, артист, год
- Жанр
- Список всех треков
- Кнопки: Play All, Shuffle, Add to Queue

**Редактирование:**
- Изменить обложку
- Исправить название
- Добавить недостающие треки
- AI помогает найти правильные метаданные

### Управление метаданными

**Проблема:** треки скачанные из интернета часто имеют неправильные названия, нет обложек, нет информации об артисте

**Решение - AI-помощник:**
- Автоматически находит правильные названия
- Скачивает обложки альбомов
- Добавляет жанры
- Находит тексты песен
- Определяет настроение и темп

**Как работает:**
- Выбираешь трек
- Жмешь "Исправить информацию"
- AI анализирует аудио и название
- Предлагает варианты исправлений
- Ты подтверждаешь или отклоняешь

**Пример:**
```
Было: "unknown_artist - track_01.mp3"
AI нашел: "Imagine Dragons - Believer"
+ добавил обложку альбома Evolve
+ добавил жанр: Alternative Rock
+ добавил год: 2017
+ нашел тексты песни
```

## 🤖 5. AI-помощник

### Где появляется

**1. На главном экране:**
- Рекомендует что послушать
- Анализирует настроение
- Предлагает плейлисты

**2. В поиске:**
- Помогает найти песни по описанию
- Исправляет опечатки
- Показывает тренды

**3. В библиотеке:**
- Исправляет метаданные
- Находит недостающую информацию
- Предлагает группировки

**4. В плеере:**
- Создает умную очередь
- Предлагает похожие треки

### Основные функции

**1. Персональные рекомендации**

Анализирует:
- Что ты слушаешь чаще всего
- В какое время какую музыку предпочитаешь
- Какие жанры любишь
- Какое настроение у музыки

Предлагает:
- Новые треки из твоей библиотеки
- Похожих артистов
- Треки под настроение

**2. Умный поиск**

Понимает запросы типа:
- "Веселая музыка" → энергичные треки с мажорной тональностью
- "Для пробежки" → быстрые треки 140+ BPM
- "Расслабляющая музыка" → медленные, спокойные композиции
- "90-е годы" → фильтрует по году выпуска

**3. Генерация плейлистов**

Примеры:
- "Создай плейлист для утренней пробежки"
  → AI подбирает энергичные треки 150-180 BPM
  
- "Музыка для концентрации"
  → спокойные треки без слов (инструментал)
  
- "Вечерний чилл"
  → расслабляющие треки разных жанров

**4. Улучшение метаданных**

Автоматически:
- Распознает треки по аудио
- Находит правильные названия и артистов
- Скачивает обложки
- Добавляет жанры и годы
- Находит тексты песен
- Определяет BPM и настроение

**5. Анализ настроения**

Для каждого трека определяет:
- Happy (веселый)
- Sad (грустный)
- Energetic (энергичный)
- Calm (спокойный)
- Aggressive (агрессивный)

Использует для:
- Умного поиска
- Рекомендаций
- Создания плейлистов

### Ограничения

**Бесплатная версия:**
- 10 AI-запросов в день
- Базовые рекомендации
- Автоматическое улучшение метаданных (ограниченно)

**Premium (будущее):**
- Неограниченные AI-запросы
- Продвинутые рекомендации
- Приоритетная обработка
- Дополнительные возможности

## ⚙️ 6. Настройки

### Категории настроек

**1. Общие**
- Язык интерфейса (Русский, English, Қазақ)
- Автоматическое сканирование новой музыки
- Где искать музыку (папки)
- Размер кэша

**2. Воспроизведение**
- Плавный переход между треками (Crossfade)
- Эквалайзер
- Усиление басов
- Качество звука
- Воспроизведение без пауз (Gapless)

**3. Темы оформления**

**Предустановленные темы:**

- **Светлая** - классическая светлая тема
- **Темная** - классическая темная тема
- **Игровая** - яркие неоновые цвета, киберпанк стиль
- **Минимализм** - монохромная, простая, без лишнего
- **Ретро** - винтажные цвета, стиль 80-90х
- **Природа** - зеленые и коричневые тона
- **Океан** - синие оттенки
- **Закат** - оранжево-фиолетовые тона

**Кастомизация темы:**
- Выбор акцентного цвета
- Скругление углов
- Размер шрифтов
- Прозрачность элементов
- Размытие фона (на основе обложки)
- Анимации (быстрые / медленные / без анимаций)

**Как темы работают:**
- Меняется всё приложение целиком
- Можно создать свою тему
- Можно поделиться темой (экспорт файла)
- Можно импортировать чужие темы

**4. AI-помощник**
- Включить/выключить AI
- Лимит запросов в день
- Автоматическое улучшение метаданных
- Умные рекомендации
- Контекстные приветствия

**5. Конфиденциальность**
- Собирать аналитику (да/нет)
- Сохранять историю прослушиваний
- Делиться данными для улучшения AI
- Отправлять отчеты об ошибках

**Важно:** все можно отключить, приложение работает и без сбора данных

**6. Хранилище**
- Очистить кэш
- Удалить все данные
- Экспорт данных (плейлисты, настройки)
- Импорт данных

**7. О приложении**
- Версия
- Что нового
- Обратная связь
- Поддержка

## 🎨 7. Дизайн и UX

### Анимации

**Переходы между экранами:**
- Плавные, естественные
- Материал дизайн стиль

**Мини-плеер → Полный плеер:**
- Expand animation (расширение)
- Обложка увеличивается
- Элементы плавно появляются

**Приветствие на главном экране:**
- Fade in/out при смене текста
- Плавное изменение размера при скролле

**Карточки треков:**
- Hover эффект (на планшете)
- Ripple при нажатии

### Цветовая схема

**Адаптивная палитра:**
- Основной цвет берется с обложки играющего трека
- Фон может иметь размытую версию обложки
- Текст автоматически подстраивается для читаемости

**Темная тема (по умолчанию):**
- Фон: глубокий черный / темно-серый
- Карточки: чуть светлее фона
- Акцент: яркий цвет (по выбору)
- Текст: белый / светло-серый

**Светлая тема:**
- Фон: белый / светло-серый
- Карточки: чуть темнее фона
- Акцент: насыщенный цвет
- Текст: черный / темно-серый

### Жесты

**Свайпы:**
- Свайп вправо на треке → добавить в очередь
- Свайп влево на треке → удалить / добавить в плейлист
- Свайп вниз в полном плеере → свернуть
- Свайп вверх на мини-плеере → развернуть

**Долгое нажатие:**
- На треке → контекстное меню (добавить в плейлист, информация, удалить)
- На плейлисте → редактировать, удалить, поделиться

**Pinch to zoom:**
- На обложке в полном плеере → увеличить обложку

## 🌐 8. Онлайн функции

### Что используется из интернета

**1. Метаданные**
- Last.fm - информация об артистах, похожие артисты
- MusicBrainz - правильные названия треков и альбомов
- Spotify API - обложки альбомов
- Genius - тексты песен

**2. AI функции**
- Собственный бэкенд для AI-запросов
- Анализ настроения
- Генерация рекомендаций
- Умный поиск

**3. Распознавание музыки**
- ACRCloud - распознать трек по аудио
- Помогает найти правильные метаданные

### Работа без интернета

**Всё основное работает локально:**
- Воспроизведение музыки
- Библиотека
- Плейлисты
- Базовый поиск
- Настройки

**Не работает без интернета:**
- AI-помощник (умный поиск, рекомендации)
- Загрузка метаданных
- Поиск текстов песен
- Распознавание треков

**Кэширование:**
- Скачанные метаданные сохраняются
- Обложки кэшируются
- Рекомендации кэшируются на день
- Тексты сохраняются локально

**Пользователь может:**
- Отключить всю аналитику
- Не сохранять историю
- Не отправлять данные для AI
- Удалить все данные
- Экспортировать свои данные
